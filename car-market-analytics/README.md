# Car Marketplace Application

Welcome to the Car Marketplace Application! This web app is designed for managing and displaying car data, featuring a user-friendly interface for highlighting and filtering cars by brand and model.

## Project Overview

The Car Marketplace Application provides a comprehensive dashboard to view and analyze car data. Users can:

- View car data categorized by brand and model.
- Highlight cars and view them on a separate page.
- Analyze car data using charts.

## Features

- **Dashboard Page**:
  - Displays car data in a table format.
  - Includes a pie chart and a stacked bar chart for visual data analysis.
- **Home Page**:
  - Shows cars categorized by brand.
  - Allows users to highlight cars and manage their selections.
- **Highlighted Cars Page**:
  - Displays cars that have been highlighted.
  - Provides functionality to remove cars from the highlighted list.

## Technologies

- **React.js**: Frontend framework for building the user interface.
- **Chart.js**: Library for rendering charts.
- **Bootstrap**: CSS framework for responsive design.
- **Local Storage**: For persisting highlighted car data.
- **pnpm**: Package manager used for dependency management.
